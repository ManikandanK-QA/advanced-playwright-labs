Advanced Playwright labs

A deterministic target application for visual, network, performance and security tests.

Every page here is served by apps/lab-site/server.mjs. The server sets the hardening headers, cookies and API behaviour that the test suite asserts against.
Visual regression Deterministic dashboard and pricing pages with fixed data, explicit image dimensions and no web fonts, so screenshots are comparable. /visual/dashboard.html /visual/pricing.html Network simulation A feed that loads over fetch, with loading, empty, error and retry states, plus a checkout form that posts JSON. /network/feed.html /network/checkout.html Performance budgets One page that is clean and one page with a deliberately injected layout shift and long task, measured with PerformanceObserver. /performance/stable.html /performance/heavy.html Browser security CSP enforcement, cookie flags, response headers and storage hygiene, asserted from the browser rather than from a written policy. /security/csp-lab.html /security/cookies-lab.html /security/storage-lab.html
